# App Review Notes

Orbitext is an independent, third-party standalone client for the Telegram messaging service on Apple Watch. It is not affiliated with, endorsed by, or sponsored by Telegram FZ-LLC or Telegram Messenger Inc. The Telegram name is used in the store description only to state compatibility (nominative use); the app name, subtitle and keywords do not contain it.

## Login

Reviewers can test login with either:

- QR login from an existing Telegram account on another device.
- Phone number login with Telegram verification code.

Some Telegram accounts may require a 2FA password after code entry.

## Capabilities

- App Groups: used to sync unread count and latest chat preview with the WidgetKit extension.
- Push Notifications: used for Telegram message alerts.
- Microphone: used to record Telegram voice messages.
- Background audio: supports voice/media playback behavior.
- Remote notification background mode: processes incoming message notifications.
