## Description

Orbitext - Apple Watch үшін жасалған тәуелсіз үшінші тарап мессенджер-клиенті, Telegram хабар алмасу қызметімен үйлесімді. QR-код немесе телефон нөмірі арқылы кіріңіз, чаттарды оқыңыз, хабарлама жіберіңіз, дауыстық хабарлама жазыңыз, медианы қараңыз, іздеуді пайдаланыңыз, хабарландыруларды басқарыңыз және оқылмаған хабарламаларды watchOS виджеті арқылы бақылаңыз.

Orbitext - бейресми клиент. Қолданба Telegram FZ-LLC және Telegram Messenger Inc. компанияларымен байланысты емес, олардың мақұлдауы немесе демеушілігі жоқ. Orbitext Telegram API-ын пайдаланады және Telegram экожүйесінің бөлігі болып табылады. Қызметке қосылу ресми ашық бастапқы кодты TDLib кітапханасы арқылы орындалады. "Telegram" - Telegram FZ-LLC компаниясының тауар белгісі, мұнда тек қызметтің үйлесімділігін сипаттау үшін қолданылады (номинативті адал пайдалану).
