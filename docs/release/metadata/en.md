## Description

Orbitext is an independent, third-party messenger client built for Apple Watch, compatible with the Telegram messaging service. Sign in with QR code or phone number, read chats, send messages, record voice messages, view media, search, manage notifications, and keep unread counts visible with a watchOS widget.

Orbitext is an unofficial client and is not affiliated with, endorsed by, or sponsored by Telegram FZ-LLC or Telegram Messenger Inc. Orbitext uses the Telegram API and is part of the Telegram ecosystem. The app connects to the Telegram service using the official open-source TDLib library. "Telegram" is a trademark of Telegram FZ-LLC, used here only to describe service compatibility (nominative fair use).
