## Promotional Text

Самостоятельный watchOS-клиент мессенджера. Входите, читайте чаты, отвечайте голосом и текстом прямо с часов.

## Description

Orbitext - независимый сторонний мессенджер-клиент для Apple Watch, совместимый с сервисом обмена сообщениями Telegram. Входите через QR-код или номер телефона, читайте чаты, отправляйте сообщения, записывайте голосовые сообщения, просматривайте медиа, используйте поиск, управляйте уведомлениями и отслеживайте непрочитанные сообщения через watchOS-виджет.

Orbitext - неофициальный клиент. Приложение не связано с Telegram FZ-LLC и Telegram Messenger Inc., не одобрено и не спонсируется ими. Orbitext использует Telegram API и является частью экосистемы Telegram. Подключение к сервису выполняется через официальную open-source библиотеку TDLib. "Telegram" - товарный знак Telegram FZ-LLC, упоминается здесь только для описания совместимости сервиса (номинативное добросовестное использование).
